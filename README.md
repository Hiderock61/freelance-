# フリーランス装備庫 v2.1

iPhoneだけで、AI時代の仕事道具・今日の進め方・納品の型を学べるフリーランス訓練アプリです。

v2.1では、入口アプリで作った「案件カード」を装備庫に貼り付けて、今日の作業と納品タブへつなぐための「案件カード受け取り欄」を追加しました。

## 公開URL

https://hiderock61.github.io/freelance-/

## v2.1で追加したこと

- 今日タブ上部に「案件カード受け取り欄」を追加
- 入口アプリで作った案件カードをコピペで貼り付け可能
- 「案件カードを読み込む」で案件名・作業内容・納品物・チェック基準を表示
- 「納品タブへ反映する」で既存の納品入力欄へ値をセット
- 保存なし、自動通信なし、新規タブ追加なし

## 想定する案件カード形式

```text
【案件カード】

■ 案件名：
〇〇

■ 入口タイプ：
〇〇

■ 作業内容：
〇〇

■ 納品物：
〇〇

■ 必要技術：
〇〇

■ 不足技術：
〇〇

■ 次の学習ミッション：
〇〇

■ 相手へ聞く質問：
〇〇

■ 応募または試作提案文：
〇〇

■ チェック基準：
〇〇
```

見出しがない文章を貼った場合は、全文を「作業内容」として扱います。

## 使い方

1. 入口アプリで案件カードをコピーします。
2. 装備庫の「今日」タブ上部にある「案件カード受け取り欄」へ貼り付けます。
3. 「案件カードを読み込む」を押します。
4. 読み込み結果を確認します。
5. 「納品タブへ反映する」を押します。
6. 納品タブの「3つのお渡しレターモード」で提出文を作ります。

## v2.0から維持していること

納品タブの「3つのお渡しレターモード」は維持しています。

- 📦 初回提出
- 🛠 修正提出
- 🚧 途中共有

入力欄は増やしすぎず、案件カードから必要な値だけを既存入力欄へ反映します。

## 制約

- 募集文解析はしません
- 応募判定はしません
- AI自動補完はしません
- localStorage保存はしません
- ログインはありません
- 自動送信はしません
- 複数案件管理はしません
- 入口アプリとの接続はコピペのみです
