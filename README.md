# フリーランス装備庫 v0.1

覚える前に、装備するためのタップ型ラーニングアプリです。

## 目的

Slack、Miro、GitHub、VS Code、Google Slides、Canva、Figma、Google Drive、AI制作班を、暗記ではなく「使う場面」「最初の一手」「公式リンク」「小ミッション」「納品での使い方」に分けて身体に入れる。

## 画面

- 装備：各ツールのカード
- 今日：地上条件別の5分から15分ミッション
- 納品：URL、スクショ、README、作戦ボード、スライドのチェックリスト
- AI：ChatGPT、Gemini、Copilot、Claudeに投げる文

## GitHub Pages

`index.html`、`style.css`、`script.js` をリポジトリ直下に置けば動きます。外部ライブラリなし、APIなし、localStorageだけ使用。
