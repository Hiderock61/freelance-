# フリーランス装備庫 v0.8

## v0.8 納品パック

v0.8では、既存の「納品」タブに、成果物を相手が確認しやすい形で渡すための「納品パック」を追加しました。

追加内容：

- 公開URL
- スクショ3枚の候補
- 一言説明
- できること3つ
- 今回の更新点
- 見てほしい場所
- 次に相談したいこと
- 提出文コピー

画像アップロードやスクショ保存はまだ入れていません。まずは「どの画面を撮ればいいか」「どんな文章で渡せばいいか」がわかる見本カードとして実装しています。

## スクショ候補

1. 今日タブ：今日の装備ルート
2. 装備タブ：温度札つき装備カード
3. 納品タブ：v0.8納品パック

## v0.8の目的

公開URLだけを渡すのではなく、相手が確認しやすい形で成果物を提出する練習をすること。

フリーランス装備庫は、道具を覚えるだけではなく、

- 見学する
- 装備する
- 今日の一手を選ぶ
- 納品の形にする

ところまでを、iPhoneだけで練習するためのWebアプリです。
