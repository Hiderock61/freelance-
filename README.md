# フリーランス装備庫 v0.9

v0.9では、納品タブに「納品パック入力版」を追加しました。

## 追加したこと

- 納品タブ上部に v0.9「お渡しパック入力版」を追加
- `✏️ 入力する` / `👀 完成文を見る` のミニ切り替えを追加
- 公開URL、一言説明、できること、更新点、見てほしい場所、次に相談したいことを編集可能に変更
- 入力内容から提出文プレビューを生成
- 提出文をコピーするボタンを追加
- コピー成功表示を追加
- v0.8の見本カードは下に残して、迷った時の参考にできるようにした

## v0.9でやらないこと

- 画像アップロード
- スクショ保存
- PDF出力
- localStorage保存
- 複数作品管理

## 確認手順

1. 納品タブを開く
2. 上部に `✏️ 入力する` と `👀 完成文を見る` が出るか確認
3. 入力欄に見本値が入っているか確認
4. `👀 完成文を見る` を押す
5. 提出文プレビューが表示されるか確認
6. `提出文をコピーする` を押す
7. `コピーしました` が出るか確認
