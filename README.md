# フリーランス装備庫 v0.5

iPhoneだけで、AI時代のフリーランス仕事に必要な「見学・共有・装備・今日・納品・監督」を体感するWebアプリです。

## v0.5 追加内容

v0.5では、装備カードに **「🎞️ 操作紙芝居を見る」** を追加しました。

Slack、Miro、VS Code、Google Slides、Figma、Canva について、本物のスクショや画像生成を使わず、HTML/CSSの疑似画面で「開いたら何が見えるか」「何を押して、何を渡すか」を紙芝居で確認できます。

## 追加された紙芝居

- Slack：仕事場の建物、部屋（チャンネル）、名前呼び出し（メンション）、URL共有
- Miro：作戦ボード、メモ（付箋）、矢印、共有リンク
- VS Code：作業机、ファイル一覧、index.html編集、保存、監督チェック
- Google Slides：説明紙芝居、タイトル、スクショ枠、共有リンク
- Figma：画面模型、フレーム、ボタン、コメント、プロトタイプ
- Canva：仕上げの一枚、テンプレ、スクショ、説明文、画像保存

## ファイル構成

```text
index.html
style.css

README.md
```

## 使い方

1. GitHub Pagesで公開する
2. 装備タブを開く
3. Slackなどのカードにある「🎞️ 操作紙芝居を見る」を押す
4. 前へ／次へで紙芝居を見る
5. 装備に戻るで装備リストへ戻る

## v0.5 完成条件

まずは Slack の操作紙芝居が iPhone で最後まで見られればOKです。

```text
装備タブ → Slackカード → 操作紙芝居を見る → 次へ → 装備に戻る
```
