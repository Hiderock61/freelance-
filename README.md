# フリーランス装備庫 v2.3.15

v2.3.15では、制作素材の場所が分からない場合に、iPhoneの「ファイル」→メール→チャット→依頼主確認の順で人間が探せる探索ナビを追加しました。探索中は制作UIを表示せず、見つかった時点で既存の現在地・素材到達導線へ合流します。

## 受取場所入力・現在地確定ヤスリ

制作素材を受け取っていても案件カードに具体的な場所がない場合は、「メール・チャット・Google Drive・Dropbox・iPhoneの『ファイル』・GitHub・その他」から、今どこから作業を始めるかを選びます。選択後は同じ制作作業台で「どこへ行く？→何を探す？→何を開く？」へ進みます。カードに場所が明記されている案件は、現在地選択を挟まず従来どおり進みます。

現在地は画面内だけの一時情報です。案件カード、カード状態、契約上の共有方法、入口アプリ、URL、localStorage、外部サービスには保存・送信しません。「その他」は空欄を許可せず、入力した場所名から最初の操作だけを生成します。経由地は推論せず、既存カードから生成した探索対象と開く対象を維持します。

## 受取場所名・重複整理ヤスリ

制作素材の受取後は、案件カード内の作業内容・納品物・素材・次の行動に具体的な場所名がある場合だけ、Google Drive、Dropbox、GitHub、メール、チャット、共有URLを「1｜どこへ行く？」へ表示します。場所名がない場合は「どこで素材を受け取ったか確認してください」と案内し、具体サービスを推測しません。

素材到達ルートでは「どこへ行く？→何を探す？→何を開く？」を唯一の主導線とし、同じ操作を直後の「今やること」へ再掲しません。ZIPは受取場所ではなくファイル形式として扱い、場所を開く→ZIPを探す→ZIPを開いて中の対象を確認する順番を維持します。受取不要案件ではv2.3.10の「今やること」を従来どおり表示します。

## 制作素材への到達・開始場所ヤスリ

素材の受取済みを人間が確認した後、案件カード内の確定情報だけを使って「どこへ行く」「何を探す」「何を開く」を順番に案内します。Google Drive、Dropbox、GitHub、メール、チャット添付、共有URLはカードに明記されている場合だけ表示し、具体的な場所がない場合は「どこで受け取ったか確認してください」で止めます。場所が分かった後は同じ画面で続行でき、カード状態は制作可能のまま変更しません。

ZIPは受取場所とはみなさず、場所を確認して開いた後に「ZIPファイルを探す」「ZIPを開く」「中の対象を確認する」「対象を開く」と案内します。各操作には、どこまでできたら完了印を付けてよいかを短く併記し、既存チェックリストより先に操作案内を表示します。v2.3.11の受取分岐、v2.3.10の最初の1操作、確認中ルート、安全停止、仕事と学習の別レーンは維持しています。

## 制作素材の受取・開始場所ヤスリ

制作可能カードでも、依頼主から受け取る修正対象ファイル・文章・画像・素材・共有データが必要な場合は、制作作業台の「今やること」より先に、対象物が手元にあるかを人間へ確認します。判定には案件カード内の作業内容・納品物・素材・次の行動だけを使い、募集文の再解析や受取済みの推測は行いません。

「まだ受け取っていない」場合は、カード状態を制作可能のまま維持し、「制作素材の受取待ち」として実制作を止めます。共有方法がカードに書かれている場合だけZIP・Google Drive・Dropbox・GitHub・メール・チャット添付を案内し、書かれていない場所は発明しません。同じ作業台の「受け取っている」から再開できます。

「受け取っている」場合は、受け取った場所を開き、対象物を確認し、現在状態を確認してから作業へ進みます。その後の最初の1操作、制作手順、検品、完成条件、仕事と学習の別レーンはv2.3.10のまま維持します。外部素材が不要な案件には受取確認を表示しません。

## 最初の操作・実行単位ヤスリ

制作可能カードの「今やること」を、仕事全体の説明ではなく、利用者が自分で実行できる最初の1操作へ変更しました。カードの作業内容・納品物・必要技術・今使える装備だけを使い、Web修正は対象HTML/CSSファイル、文章は対象文章、画像は対象画像、ページ作業は対象ページを開く案内へ分けます。対象を特定できない場合は「作業内容に書かれた対象を確認します」と安全に止め、ファイル名・URL・ツールを発明しません。

仕事全体は既存の「今回の仕事」「今日やること」「制作手順」に残し、最初の1操作の後へ「このあと進める流れ」を表示します。チェックは作業後の完了印、仕事と学習の別レーン、検品・完成条件・装備、v2.3.8の人間語UX、v2.3.7の未確定事項・質問整合、安全停止を維持しています。

## 制作開始・最初の一手ヤスリ

制作可能カードの作業台冒頭へ「今やること」「最初の具体的な一手」「作業の進め方」「チェックは作業後に付ける完了印」を追加しました。

最初の一手はカードの作業内容、作業順は既存の制作手順・チェック基準・納品物から表示し、募集文の再解析やカード外情報の推測は行いません。

「先に学ぶ」は制作開始前のチェック項目から外し、学習内容を削除せず「今回学ぶこと」へ保持します。今日やること、制作手順、検品、完成条件、装備、v2.3.8の人間語UX、v2.3.7の未確定事項・質問整合、安全停止は維持しています。

## 内部語を隠す・制作開始案内ヤスリ

入口アプリから受け取った内部の案件カード形式と「確認中／制作可能」の判定値は維持したまま、通常画面では「仕事の内容を確認しました」「この仕事はまだ確認が必要です」「この仕事は制作を始められます」と普通の仕事の言葉で案内します。

確認中では、v2.3.7で整合した未確定事項の配列から件数を動的に表示し、不足項目、質問、まとめてコピー、自分で送信、回答後に入口アプリへ戻る流れを一本道で表示します。制作可能では、必要情報が揃った理由と「今日やる作業を見る」を表示し、既存の制作作業台へ進みます。

カード解析、状態分岐、未確定事項と質問の整合、安全停止、制作作業台、6タブ、納品3モードは変更していません。

## 未確定事項・質問整合ヤスリ

確認中カードでは、入口アプリから受け取った「相手へ聞く質問」を正本として「まだ確認が必要なこと」を表示します。「修正対象ファイル」という質問を「修正回数と修正範囲」へ誤分類せず、確定済み情報を未確定へ戻しません。作業内容・納品物・チェック基準と、カードに独立記載された素材・修正回数・制作開始許可は「ここまで分かっています」へ表示します。カードにない値は推測しません。

## 確認中カード状態の表示不一致ヤスリ
確認中専用画面の「読み取った案件」では、内部判定に使った `カード状態` の正式値をそのまま表示します。作業内容・納品物・チェック基準の未確定判定とは分離し、`確認中` を `未確定` へ変換しません。確認中／制作可能の分岐ロジックと状態なしカードの安全停止は変更していません。

## 入口アプリからの着地点ヤスリ
通常起動時の見学タブ上部に「入口アプリの案件カードを貼る」ボタンを追加しました。押すと今日タブを開き、案件カード受付欄へ移動します。

`#today` または `#card-intake` 付きURLで開いた場合も、今日タブの案件カード受付欄を直接表示します。カード本文の自動貼り付けは行わず、コピー＆ペースト方式を維持しています。

今日タブの受付手順を5段階にし、白い貼り付け欄と読み取りボタンをiPhoneで見つけやすくしました。確認中カードでは案件名・作業内容・納品物・チェック基準を表示し、未確定値は「未確定」と明示します。

## 今回の追加
確認中カードでは0/5形式の制作作業台を表示せず、「状態・今やること・未確定事項・依頼主へ聞く質問・質問コピー・入口アプリへ戻る」の確認専用パネルを表示します。制作可能カードの既存作業台は維持しています。

iPhone表示では、固定下部ナビ分の余白とsafe-areaを追加し、「6つのタブの役割」の本文列が極端に細くならないよう列幅と改行規則を補修しました。

確認中カードの整理チェックを具体的な5項目へ変更し、未確定事項と質問を見比べやすい表示へ整理しました。5項目の進捗は既存の自動集計で連動します。

確認中カードの確認作業台へ、チェックの意味、質問は自動送信されないこと、回答後に入口アプリへ戻ってカードを更新する8段階の流れを追加しました。制作可能カードの作業台は変更していません。

今日タブ上部の案件カード受け取り口へ、コピー元・貼り付け場所・読み取り後の行動が分かる4段階の操作案内を追加しました。解析方式とカード状態分岐はv2.3のままです。

入口アプリ v0.4D が作った案件カードの【カード状態】を読み取り、作業台を安全に分岐します。

- `確認中`：未確定事項と質問を扱う確認作業台を表示し、実制作・完成・納品へ進めません。
- `制作可能`：既存の制作作業台を表示します。
- 状態なし／不明：処理を停止し、最新カードの再発行を案内します。
- 制作可能でも作業内容・納品物・チェック基準が未確定なら停止します。

制作可能カードは、次の5つへ並べ替えます。

1. 今日やること
2. 今回学ぶこと
3. 制作手順
4. 検品すること
5. 完成条件

## 安全ルール
- 案件カードから納品文へ自動反映しません。
- 案件カードにない完成内容を作りません。
- 必須項目が足りない場合は、作業台を作らず不足項目を表示します。
- 装備庫側でカード状態を変更せず、未確定情報を補完しません。
- 納品タブには、実際に作業が終わった後の事実だけを入力します。
- 保存・送信は行いません。
