# フリーランス装備庫 v0.6

## 今回の追加

v0.6では、装備カードに「温度札」を追加しました。

- 🧊 今はスルー
- 👀 眺めるだけ
- 👆 1回さわる
- 🧰 制作本線

これにより、Slack、Miro、VS Code、Figmaなどを見た時に「今すぐ覚えないといけないのか？」という圧を下げられます。

## v0.6の目的

全部のITツールを一気に覚えるのではなく、今の自分との距離感を見ること。

たとえば：

- Miro：🧊 今はスルー。作戦ボードという概念だけ棚に置く。
- Slack：👀 眺めるだけ。仕事場・部屋・名前呼び出しの構造だけ見る。
- Google Slides：👆 1回さわる。3枚の説明紙芝居を作る練習に向く。
- GitHub：🧰 制作本線。ファイル管理、commit、公開URLづくりで使う。

## v0.5.1から引き継いでいるもの

- 装備カード
- 操作紙芝居を見るボタン
- Slack / Miro / VS Code / Google Slides / Figma / Canva の疑似画面紙芝居
- iPhone向け縦圧縮レイアウト
- GitHub Pages対応
