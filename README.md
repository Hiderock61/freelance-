## このアプリは何？

フリーランス装備庫は、AIと一緒に仕事をするための「装備図鑑」と「訓練場」を合わせたアプリです。

Slack、Miro、GitHub、Googleドキュメント、Googleスライドなどの道具名を暗記するためのアプリではありません。

目的は、AI時代の仕事で必要になる以下の感覚を、スマホだけで少しずつ身につけることです。

* 仕事の流れを見る
* 共有の意味を理解する
* 道具の役割を知る
* 今日できる小さな行動に落とす
* URL、スクショ、説明文として納品する
* AIが出したコードや提案を、そのまま貼る前に監督する

---

## 主な機能

### 👁️ 見学

ホワイトカラーAI仕事の1日の流れをスライド形式で見ます。

例：

* 朝：Slackで連絡を見る
* 午前：Miroで作戦ボードを見る
* 昼：仕様や説明文を見る
* 午後：スライドで順番に説明する
* 夕方：URLで成果物を共有する
* 最後：納品パックにまとめる

### 🧭 ロードマップ

フリーランスAI仕事の成長ロードマップを表示します。

ステップ：

```text id="yabfkk"
0. 地下1階：入口
1. 見学
2. 共有
3. 装備
4. 今日
5. 納品
6. 監督
7. ゴール
```

### 🔑 共有

共有を「ネット上の部屋に入る鍵を渡すこと」として理解します。

扱うもの：

* 自分だけ
* 閲覧権限
* コメント権限
* 編集権限
* 画面共有
* 公開URL
* スクショ共有

### 🧰 装備

AI時代の仕事で出てくる道具の役割を整理します。

例：

* Slack
* Miro
* GitHub
* VS Code
* Google Slides
* Canva
* Figma
* Google Drive

### 📍 今日

iPhoneだけでできる小ミッションに落とします。

### 📦 納品

URL、スクショ、README、説明文、共有リンク、作業ログなどを、納品パックとして確認します。

### 🕵️ 監督

AIが出したコードや提案を貼る前に、次のような点を確認します。

* 完全版か差分か
* 上書きしていいのか
* 貼り足すだけなのか
* どのファイルに入れるのか
* GitHub用なのか、確認用なのか
* 既存機能を壊さないか
