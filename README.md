# フリーランス装備庫 v2.2

## 今回の追加
入口アプリが作った案件カードを、次の5つへ並べ替える「案件カード作業化機能」を追加しました。

1. 今日やること
2. 今回学ぶこと
3. 制作手順
4. 検品すること
5. 完成条件

## 安全ルール
- 案件カードから納品文へ自動反映しません。
- 案件カードにない完成内容を作りません。
- 必須項目が足りない場合は、作業台を作らず不足項目を表示します。
- 納品タブには、実際に作業が終わった後の事実だけを入力します。
- 保存・送信は行いません。

## アップロード
ZIPを展開し、次の4ファイルをリポジトリ直下へ上書きしてください。

- index.html
- style.css
- script.js
- README.md
