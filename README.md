# フリーランス装備庫 v0.7

AI時代のフリーランス仕事で出てくる道具を、iPhoneだけで見学・整理・練習するための小さなWebアプリです。

## v0.7 今日の装備ルート

v0.7では、既存の「今日タブ」に「今日の装備ルート」を追加しました。

v0.6で装備ごとの温度札が入り、各ツールをどう扱えばいいかが見えるようになりました。

- 🧊 今はスルー
- 👀 眺めるだけ
- 👆 1回さわる
- 🧰 制作本線

v0.7では、その温度札を「今日の行動」に変換します。

今日タブで以下の4つから1つ選ぶと、今日の3ステップが表示されます。

- 🧊 省エネ：今日は無理に触らない。閉じてもOK
- 👀 見る：SlackやVS Codeなどを、紙芝居で眺める
- 👆 さわる：Google SlidesやCanvaなどを、1回だけ試す候補を見る
- 🧰 本線：GitHub PagesやREADMEなど、公開・制作に直結する確認をする

## v0.7で追加したこと

- 今日タブに2×2のルートボタンを追加
- ルートを押すと3ステップを表示
- 紙芝居があるステップだけ「紙芝居を見る」ボタンを表示
- 既存の `openStory(storyKey)` と接続
- 新規タブは追加しない
- v0.6の装備カード・温度札・操作紙芝居はそのまま維持

## 使い方

1. `index.html`
2. `style.css`
3. `script.js`
4. `README.md`

この4ファイルをGitHubリポジトリにアップロードしてください。

GitHub Pagesで公開している場合は、アップロード後にiPhoneで表示を確認してください。

## 確認ポイント

1. 今日タブを開く
2. 🧊 省エネ / 👀 見る / 👆 さわる / 🧰 本線 の4ボタンが出る
3. ボタンを押すと3ステップが出る
4. 👀 見るルートで「紙芝居を見る」を押すとSlackやVS Codeの紙芝居へ移動する
5. 装備カードやv0.6温度札が壊れていない
