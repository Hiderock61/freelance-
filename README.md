# フリーランス装備庫 v0.4.2.2

iPhoneだけで、フリーランスAI仕事の流れ、共有、装備、納品、監督を体感する静的Webアプリです。

## v0.4.2 の追加

- 見学タブ上部に「フリーランスAI仕事ロードマップ」を追加
- 0 地下1階：入口 → 1 見学 → 2 共有 → 3 装備 → 4 今日 → 5 納品 → 6 監督 → 7 ゴール
- 各ロードマップカードから対応タブへ移動できます

## 既存機能

- 見学モード：ホワイトカラーAI仕事の1日を紙芝居で見る
- 共有モード：閲覧、コメント、編集、画面共有、公開URL、スクショ共有を体感
- 装備モード：Slack、Miro、GitHub、Google Slides、Driveなどの役割を知る
- 今日モード：iPhoneだけでできる小ミッション
- 納品モード：URL、スクショ、README、説明文の納品パック
- 監督モード：完全版/差分、上書き/貼り足し、ファイル名、GitHub用/確認用を確認

## GitHub Pages

この4ファイルをリポジトリ直下に置き、Pagesを `main / root` で有効化してください。

- `index.html`
- `style.css`
- `script.js`
- `README.md`
