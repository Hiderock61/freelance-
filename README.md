# フリーランス装備庫 v0.7.1

## v0.7.1 実機補修

v0.7.1では、v0.7「今日の装備ルート」の機能はそのままに、iPhone実機で見えた縦方向の圧と下部ナビの近さを補修しました。

主な変更点：

- 今日タブの下部余白を追加
- 今日の装備ルートカードの余白を少し圧縮
- 2×2ルートボタンを少しコンパクト化
- 3ステップカードの余白を調整
- 紙芝居画面の下部ナビかぶりを軽減
- キャッシュ対策を `v=071` に更新

機能追加はしていません。

v0.7で入れた以下の機能は維持しています。

- 🧊 省エネ
- 👀 見る
- 👆 さわる
- 🧰 本線
- 3ステップ表示
- 「紙芝居を見る」ボタン
- `openStory(storyKey)` 連携

## GitHub Pages 用ファイル

以下の4ファイルをリポジトリ直下へ上書きしてください。

1. `index.html`
2. `style.css`
3. `script.js`
4. `README.md`

個別ファイル版を使う場合は、以下のようにリネームしてください。

- `v071_index.html` → `index.html`
- `v071_style.css` → `style.css`
- `v071_script.js` → `script.js`
- `README_v071.md` → `README.md`

## 確認ポイント

1. 今日タブを開く
2. 2×2のルートボタンが見える
3. 👀 見るを押す
4. 3ステップが表示される
5. 「紙芝居を見る」でSlackまたはVS Code紙芝居へ飛ぶ
6. 下部ナビに内容が食われすぎていないか確認する
