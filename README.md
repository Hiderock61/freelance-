# フリーランス装備庫 v0.2

PCがなくても、iPhoneだけでホワイトカラーAI仕事の流れと装備の意味を体感する静的Webアプリです。

## v0.2 追加

- 👁️ 見学モードを追加
- 「ホワイトカラーAI仕事の1日」を6枚のスライドで表示
- 下部ナビを「見学 / 装備 / 今日 / 納品 / AI」の5タブ化
- 既存の装備カード、今日の一手、納品パック、AIプロンプトは維持

## 使い方

GitHub Pagesに `index.html`、`style.css`、`script.js` を置くだけで動きます。


## v0.2 第2段階

共有タブを追加。共有＝ネット上の部屋へ入る鍵を渡すこと、という考え方で、自分だけ・閲覧・コメント・編集・画面共有・公開URL・スクショ共有をiPhoneで体感できる。
