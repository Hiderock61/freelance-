# フリーランス装備庫 v2.3.7

## 未確定事項・質問整合ヤスリ

確認中カードでは、入口アプリから受け取った「相手へ聞く質問」を正本として「まだ確認が必要なこと」を表示します。「修正対象ファイル」という質問を「修正回数と修正範囲」へ誤分類せず、確定済み情報を未確定へ戻しません。作業内容・納品物・チェック基準と、カードに独立記載された素材・修正回数・制作開始許可は「ここまで分かっています」へ表示します。カードにない値は推測しません。

## 確認中カード状態の表示不一致ヤスリ
確認中専用画面の「読み取った案件」では、内部判定に使った `カード状態` の正式値をそのまま表示します。作業内容・納品物・チェック基準の未確定判定とは分離し、`確認中` を `未確定` へ変換しません。確認中／制作可能の分岐ロジックと状態なしカードの安全停止は変更していません。

## 入口アプリからの着地点ヤスリ
通常起動時の見学タブ上部に「入口アプリの案件カードを貼る」ボタンを追加しました。押すと今日タブを開き、案件カード受付欄へ移動します。

`#today` または `#card-intake` 付きURLで開いた場合も、今日タブの案件カード受付欄を直接表示します。カード本文の自動貼り付けは行わず、コピー＆ペースト方式を維持しています。

今日タブの受付手順を5段階にし、白い貼り付け欄と読み取りボタンをiPhoneで見つけやすくしました。確認中カードでは案件名・作業内容・納品物・チェック基準を表示し、未確定値は「未確定」と明示します。

## 今回の追加
確認中カードでは0/5形式の制作作業台を表示せず、「状態・今やること・未確定事項・依頼主へ聞く質問・質問コピー・入口アプリへ戻る」の確認専用パネルを表示します。制作可能カードの既存作業台は維持しています。

iPhone表示では、固定下部ナビ分の余白とsafe-areaを追加し、「6つのタブの役割」の本文列が極端に細くならないよう列幅と改行規則を補修しました。

確認中カードの整理チェックを具体的な5項目へ変更し、未確定事項と質問を見比べやすい表示へ整理しました。5項目の進捗は既存の自動集計で連動します。

確認中カードの確認作業台へ、チェックの意味、質問は自動送信されないこと、回答後に入口アプリへ戻ってカードを更新する8段階の流れを追加しました。制作可能カードの作業台は変更していません。

今日タブ上部の案件カード受け取り口へ、コピー元・貼り付け場所・読み取り後の行動が分かる4段階の操作案内を追加しました。解析方式とカード状態分岐はv2.3のままです。

入口アプリ v0.4D が作った案件カードの【カード状態】を読み取り、作業台を安全に分岐します。

- `確認中`：未確定事項と質問を扱う確認作業台を表示し、実制作・完成・納品へ進めません。
- `制作可能`：既存の制作作業台を表示します。
- 状態なし／不明：処理を停止し、最新カードの再発行を案内します。
- 制作可能でも作業内容・納品物・チェック基準が未確定なら停止します。

制作可能カードは、次の5つへ並べ替えます。

1. 今日やること
2. 今回学ぶこと
3. 制作手順
4. 検品すること
5. 完成条件

## 安全ルール
- 案件カードから納品文へ自動反映しません。
- 案件カードにない完成内容を作りません。
- 必須項目が足りない場合は、作業台を作らず不足項目を表示します。
- 装備庫側でカード状態を変更せず、未確定情報を補完しません。
- 納品タブには、実際に作業が終わった後の事実だけを入力します。
- 保存・送信は行いません。
