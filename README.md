# フリーランス装備庫 v0.6

iPhoneだけで、AI時代のフリーランス仕事に必要な装備を「見学・共有・装備・今日・納品・監督」の流れで体感するためのWebアプリです。

v0.6では、各装備に「今どう扱えばいいか」を示す **温度札** を追加しました。

## v0.6 装備の温度札

v0.6では、各装備カードと操作紙芝居に「温度札」を追加しました。

温度札は以下の4種類です。

- 🧊 今はスルー：今は深追いしなくてよい装備
- 👀 眺めるだけ：画面の形だけ見ればよい装備
- 👆 1回さわる：1回だけ試す価値がある装備
- 🧰 制作本線：現在の制作や公開で実際に使う装備

v0.5.1までで、Slack、Miro、VS Code、Google Slides、Figma、Canva などの操作紙芝居を見られるようになりました。

ただし、ツールが増えると「全部覚えないといけないのか？」という圧が出ます。

そこでv0.6では、道具ごとに距離感を表示することで、今やる装備、眺めるだけの装備、今はスルーしてよい装備を分けられるようにしました。

この更新により、フリーランス装備庫は「道具を説明するアプリ」から、「今どう扱えばいいかまで示す装備整理アプリ」に進化しました。

## 温度札の例

- Miro：🧊 今はスルー。作戦ボードという概念だけ棚に置く。
- Slack：👀 眺めるだけ。仕事場・部屋・名前呼び出しの構造だけ見る。
- VS Code：👀 眺めるだけ。左にファイル、右に中身が出る構造だけ見る。
- Google Slides：👆 1回さわる。3枚の説明紙芝居を作る練習に向く。
- Canva：👆 1回さわる。テンプレを1つ触って雰囲気を見る。
- GitHub：🧰 制作本線。ファイル管理、commit、公開URLづくりで使う。
- GitHub Pages：🧰 制作本線。作ったものをURLで見せるために使う。

- iPhone向け縦圧縮レイアウト

## 主な画面

- 👁️ 見学：ホワイトカラーAI仕事の流れを見る
- 🔑 共有：共有リンク、閲覧、コメント、編集などを理解する
- 🧰 装備：仕事道具の役割と温度札を見る
- 📍 今日：iPhoneだけでできる小ミッションを見る
- 📦 納品：URL、スクショ、README、説明文などを確認する
- 🕵️ 監督：AI出力を貼る前に確認する

## v0.6 確認ポイント

1. 装備カードに温度札が出る
2. Google Slides が「👆 1回さわる」と表示される
3. Slack が「👀 眺めるだけ」と表示される

## 完成ログ

v0.6では、ツールを増やすことではなく、「全部覚えなきゃ」という圧を下げることを目的にしました。

これにより、今すぐ使う装備、1回だけ触る装備、眺めるだけの装備、今はスルーする装備を分けて扱えるようになりました。
