# フリーランス装備庫 v2.1.1

iPhoneだけで、AI時代の仕事道具・今日の進め方・納品の型を学べるフリーランス訓練アプリです。

v2.1.1は、v2.1で追加した「案件カード受け取り欄」の視認性を補修した小修正版です。新機能は追加していません。

## 公開URL

https://hiderock61.github.io/freelance-/

## v2.1で追加したこと

- 今日タブ上部に「案件カード受け取り欄」を追加
- 入口アプリで作った案件カードをコピペで貼り付け可能
- 「案件カードを読み込む」で案件名・作業内容・納品物・チェック基準を表示
- 「納品タブへ反映する」で既存の納品入力欄へ値をセット
- 保存なし、自動通信なし、新規タブ追加なし

## v2.1.1で補修したこと

- 案件カード受け取り欄の背景色と文字色を調整
- プレビュー欄の文字が読みにくい問題を補修
- textarea のプレースホルダーを読みやすく調整
- CSS / JS 読み込みを `?v=211` にしてキャッシュ回避

## 想定する案件カード形式

```text
【案件カード】

■ 案件名：
〇〇

■ 入口タイプ：
〇〇

■ 作業内容：
〇〇

■ 納品物：
〇〇

■ 必要技術：
〇〇

■ 不足技術：
〇〇

■ 次の学習ミッション：
〇〇

■ 相手へ聞く質問：
〇〇

■ 応募または試作提案文：
〇〇

■ チェック基準：
〇〇
```

見出しがない文章を貼った場合は、全文を「作業内容」として扱います。

## 制約

- 募集文解析はしません
- 応募判定はしません
- AI自動補完はしません
- localStorage保存はしません
- ログインはありません
- 自動送信はしません
- 複数案件管理はしません
- 入口アプリとの接続はコピペのみです
