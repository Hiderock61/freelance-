# フリーランス装備庫 v1.0

フリーランス装備庫は、AI時代の仕事道具を全部覚えるためのアプリではありません。

Slack、GitHub、Figma、Canvaなどの道具を、iPhoneだけで「見学する」「今日の一手を選ぶ」「相手に渡す形にする」ための訓練アプリです。

全部やらなくてOK。今の状態に合わせて、見学 → 装備 → 今日 → 納品 の順に少しずつ進めます。

## はじめての人はここから

1. **見学**：仕事の1日の流れを見る
2. **装備**：道具の温度札を見る
3. **今日**：今日の3ステップを選ぶ
4. **納品**：提出文を作る

## 6つのタブの役割

- 👁 **見学**：仕事の1日の流れを見る
- 🔑 **共有**：URL・権限・コメントの感覚を知る
- 🧰 **装備**：道具ごとの距離感を見る
- 📍 **今日**：今日の3ステップを選ぶ
- 📦 **納品**：提出文を作る
- 🕵️ **監督**：AI出力をそのまま貼らないために確認する
