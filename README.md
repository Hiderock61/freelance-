# フリーランス装備庫 v2.0.1

iPhoneだけで、AI時代の仕事道具・今日の進め方・納品の型を学べるフリーランス訓練アプリです。

v2.0.1は、v2.0の新機能を増やさず、作品化前の小補修だけを行った版です。

## 公開URL

https://hiderock61.github.io/freelance-/

## v2.0で追加したこと

納品タブの「完成文を見る」側で、提出文の種類を3つから選べるようにしました。

- 📦 初回提出
- 🛠 修正提出
- 🚧 途中共有

入力欄は増やさず、同じ入力内容から状況別の提出文を作れます。

## v2.0.1で補修したこと

- トップのバージョン表記を v2.0.1 に更新
- CSS / JS の読み込みに `?v=201` を付けてキャッシュ回避
- 納品タブの公開URL初期値を以下に修正

```text
https://hiderock61.github.io/freelance-/
```

- 新機能は追加していない
- リポジトリ内の古いファイル削除は行っていない

## 触った範囲

- index.html
- script.js
- README.md

style.css は v2.0 の表示が大きく崩れていなかったため、今回は大きな変更なし。

## v2.0.1の方針

v2.0.1は補修版です。保存機能、画像アップロード、PDF出力、ログイン、新規タブ追加は行いません。

v2.0で完成した「3つのお渡しレターモード」を守り、作品化前に公開URL初期値と表記だけを整える版として扱います。
