# フリーランス装備庫 v0.4

**iPhoneだけで、AI時代のフリーランス仕事に必要な「見学・共有・装備・今日・納品・監督」の流れを体感するためのWebアプリです。**

これは完成版の業務ツールではなく、学習用・実験用のプロトタイプです。  
目的は、Slack、Miro、GitHub、Googleドキュメント、Googleスライドなどのツール名を暗記することではありません。

目的は、AI時代の仕事で必要になる以下の感覚を、スマホだけで少しずつ身につけることです。

- 仕事の流れを見る
- 共有の意味を理解する
- 道具の役割を知る
- 今日できる小さな行動に落とす
- URL・スクショ・説明文として納品する
- AIが出したコードや提案を、そのまま貼る前に監督する

---

## コンセプト

フリーランス装備庫は、AIと一緒に仕事をするための「装備図鑑」と「訓練場」を合わせたアプリです。

従来の学習アプリのように、専門用語を順番に暗記することは目指していません。

代わりに、以下のようなホワイトカラー仕事の見えにくい概念を、タップしながら体感できる形にしています。

- 共有とは何か
- 閲覧権限、コメント権限、編集権限の違い
- スクショ共有とURL共有の違い
- GitHub Pagesで成果物を公開するとは何か
- Google DriveやGoogle Slidesは何のために使うのか
- 納品パックとは何か
- AIが出したコードを貼る前に、何を確認するべきか

## 主な機能

### 👁️ 見学

ホワイトカラーAI仕事の1日の流れをスライド形式で見ます。

例：

- 朝：Slackで連絡を見る
- 午前：Miroで作戦ボードを見る
- 昼：仕様や説明文を見る
- 午後：スライドで順番に説明する
- 夕方：URLで成果物を共有する
- 最後：納品パックにまとめる

---

### 🧭 ロードマップ

見学タブの上部に、フリーランスAI仕事の成長ロードマップを表示します。

ステップ：

0. 地下1階：入口
1. 見学
2. 共有
3. 装備
4. 今日
5. 納品
6. 監督
7. ゴール

それぞれのステップから、対応するタブへ移動できます。

---

### 🔑 共有

「共有＝ネット上の部屋に入る鍵を渡すこと」として、共有の種類をカードで理解します。

入っている共有カード：

- 🔒 自分だけ
- 👀 閲覧権限
- 💬 コメント権限
- ✏️ 編集権限
- 📺 画面共有
- 🌐 公開URL
- 📸 スクショ共有

---

### 🧰 装備

仕事で使う道具を「何のための道具か」で確認します。

例：

- Slack：連絡
- Miro：作戦ボード
- Google Docs：文章
- Google Slides：説明資料
- Google Drive：保存と共有
- GitHub：コードと公開
- Canva：見た目づくり
- Figma：画面設計

---

### 📍 今日

今の状態に合わせて、iPhoneだけでできる小さなミッションを確認します。

例：

- 見学スライドを1周する
- 共有カードを1枚読む
- 装備カードを1つ開く
- AIに聞く文をコピーする
- 納品パックを1項目チェックする

---

### 📦 納品

フリーランス仕事で必要になる「渡せる形」を確認します。

納品パック：

- 公開URL
- スクショ
- README
- 説明文
- 共有リンク
- 作業ログ

---

### 🕵️ 監督

AIが出したコードや提案を、そのまま貼る前に確認するためのモードです。

監督カード：

- 完全版？差分？
- 上書き？貼り足し？
- どのファイル？
- 古い？新しい？
- GitHub用？確認用？
- 既存を壊さない？
- 文脈のバトン

AI時代の制作では、コードを全部自分で書けることだけが重要なのではなく、AIの出力をどこにどう入れるかを判断する力が重要になります。

このモードでは、その「差分監督力」を体感します。

## ファイル構成

```text
index.html
style.css
script.js
README.md
```

GitHub Pagesで公開する場合は、この4ファイルを同じリポジトリ直下に置きます。

---

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作る
2. `index.html`、`style.css`、`script.js`、`README.md` をアップロードする
3. Settings を開く
4. Pages を開く
5. Build and deployment を `Deploy from a branch` にする
6. Branch を `main`、Folder を `/root` にする
7. Saveする
8. 数分待って公開URLを開く

---

## このアプリで目指すこと

このアプリのゴールは、単にツールを覚えることではありません。

最終ゴールは、以下の状態です。

```text
説明できて、再現できて、納品できる人になる
```

具体的には：

- 自分の作業を説明できる
- AIに同じ作業を再現させられる
- 納品パックを作れる
- 共有権限を理解している
- AIの出力を監督できる

## 開発メモ

このアプリは、iPhone中心の環境でもAIと相談しながら作れることを検証するためのプロトタイプです。

制作では、複数のAIを役割分担して使っています。

- ChatGPT：構造整理、統合判断、仕様化
- Gemini：外向き説明、コンセプト整理
- Copilot：実装案、差分パッチ設計

この制作プロセス自体も、アプリのテーマである「AI時代の仕事の進め方」の実例になっています。
